# 划词翻译(免费)（Microsoft Edge）

版本：1.0.33

插件开启后，在网页中选中文字并松开鼠标或结束触屏选择时，会立即显示译文卡片；键盘选择文本时，在按键操作结束后触发。卡片提供源语言和目标语言选择器；源语言默认自动检测，也可以手动选择。点中间的交换按钮会把当前译文作为新原文，按反向语种再翻译。

译文卡片不会因页面滚动或鼠标移出而关闭；点击卡片的关闭按钮或卡片外部即可关闭。之后选中新的文本会再次显示翻译卡片。

## 安装

1. 打开 Edge，进入 `edge://extensions`。
2. 打开左侧或右上方的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本文件夹 `edge-bilingual-translator`。
4. 打开普通网页并选中文字，松开鼠标或结束触屏选择即可自动翻译。第一次使用时，如果 Edge 询问扩展对网站的访问权限，请允许。

点击 Edge 工具栏上的扩展图标，可以随时开启或关闭自动翻译功能。开关状态会保存在当前浏览器中。

弹窗可以开启或关闭翻译，也可以手动选择 Google 翻译、搜狗翻译或有道翻译；首次默认使用搜狗翻译，之后保留用户选择。翻译服务选项会保存在当前浏览器中。

## 使用说明

- 语言列表包含 Google 网页翻译提供的 249 个语种。手动选择时，简体/繁体中文置顶，随后按主要留学目的地公开中国学生人数优先显示英语、日语、韩语、俄语、法语、德语和泰语；英语合并美国、英国、澳大利亚、加拿大等目的地考虑。其余语种沿用 Google 原列表顺序。各国数据年份及统计口径不同，因此这是便于常用语种优先选择的排序。
- 非中文选区默认译为简体中文；检测到中文时默认译为英语。用户也可以手动选择源语言或目标语言。
- 交换按钮会把当前译文设为新的原文，并交换源语言和目标语言；例如中文译成日语后，可以交换成日语译回中文。
- 每次划词最多发送一个翻译请求，不会把长文本拆成多个请求再拼接。超过服务单次上限时会提示缩短选区。
- Google 单次请求 URL 和搜狗单次 JSON 请求体上限均为 16384 字节；有道单次表单请求体上限为 640 字节。上限均按实际编码后的请求字节数判断，不另设字符数或句子数上限。
- 翻译卡片显示当前选中文字的 UTF-8 字节数与服务提示上限：Google 和搜狗为 16384 字节，有道为 640 字节。
- Google 翻译使用 Google 网页端接口；搜狗翻译使用搜狗网页端文本翻译接口；有道使用移动网页翻译接口。它们都不需要用户填写 API 密钥，但网页接口可能调整、限流或停止响应。
- 搜狗网页接口目前仅支持简体中文与英语、日语、韩语互译；有道网页接口目前仅支持中文与英语、日语、韩语、法语、俄语、西班牙语互译。其他语种组合会提示切换翻译服务。Google 网页端接口在中国大陆的可用性取决于网络环境。
- 搜狗的“自动检测”会根据文本字符和常见字母特征进行本地推测；混合文本或相近的拉丁字母语种建议手动选择源语言。Google 由接口自动检测。
- 腾讯翻译、必应翻译和讯飞翻译当前网页含验证码或登录会话流程，因此没有加入；翻译狗页面当前脚本请求返回 403，未能确认可匿名使用的文本接口，也没有加入。
- 扩展不会处理或绕过验证码、行为校验或反自动化令牌；遇到此类校验的服务不加入可选列表。
- 浏览器内置页面（例如 `edge://extensions`）、Edge 新标签页以及部分受限网页不允许扩展注入脚本，因此无法在这些页面划词翻译。
- 当前版本针对网页正文选区；不会读取输入框、密码框或文本编辑器中的选区。
